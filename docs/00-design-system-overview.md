# Milo design system overview

This public document describes the visible design principles used in the public interface snapshot. Internal product, security, privacy, research, and production architecture are not part of this repository.

## Principles

- Keep the writing itself visually central.
- Use quiet, predictable navigation and stable layouts.
- Make support available without making it feel mandatory.
- Use plain language and age-appropriate controls.
- Preserve readable contrast, keyboard focus, and touch targets.
- Prefer shared tokens and components over page-specific styling.

## Surface hierarchy

1. Student writing and assignment content
2. Current section and navigation
3. Optional writing support
4. Progress and status information

The public snapshot uses the same shared visual foundation for its teacher setup and student workspace. Production-only behavior is intentionally excluded.
