# Interaction and motion

Milo favors stable state changes over decorative animation.

## Interaction rules

- Keep navigation in predictable locations.
- Return focus to the relevant control after a modal or temporary panel closes.
- Announce important status changes without moving the writing area.
- Avoid pulsing, bouncing, or looping motion.
- Replace loading content in place when possible.
- Respect `prefers-reduced-motion`.

Motion should clarify cause and effect. It should never be required to understand progress, status, or available actions.
