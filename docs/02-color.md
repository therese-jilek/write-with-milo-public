# Color

The public snapshot uses a restrained palette with distinct roles.

| Role | Value |
| --- | --- |
| Brand plum | `#4B2E83` |
| Soft lavender | `#EEE9FA` |
| Page background | `#F8F6FC` |
| Cool student environment | `#F3F9FE` |
| Active writing band | `#FFF8E8` |
| Surface | `#FFFFFF` |
| Primary text | `#272334` |
| Secondary text | `#6B657A` |
| Quiet border | `#DED8EE` |

Color reinforces hierarchy but does not replace labels, focus treatment, marker shapes, or status text.
