# Typography

Milo uses a familiar sans-serif foundation so the interface remains readable and visually quiet.

## Roles

| Role | Guidance |
| --- | --- |
| Wordmark | Strong, compact, deep plum |
| Page title | Clear hierarchy without oversized display text |
| Section title | Prominent enough to orient the writer |
| Student writing | Generous line height and a comfortable reading size |
| Support title | Smaller than the writing-section title |
| Helper/status text | Quiet secondary color; never the only source of meaning |

Text sizes are fixed by role rather than scaled with viewport width. Responsive layouts reflow instead of shrinking important text.
