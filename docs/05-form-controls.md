# Form controls

Forms use native HTML controls with consistent labels, spacing, borders, and focus treatment.

## Guidelines

- Every input has a visible label or an equivalent accessible name.
- Placeholder text is not a replacement for a label.
- Textareas use comfortable line height and preserve entered text during responsive reflow.
- Validation messages appear near the related control and are announced when appropriate.
- Hidden implementation details are not presented as editable controls.

The public teacher setup demonstrates select and textarea patterns without connecting to accounts or persistence.
