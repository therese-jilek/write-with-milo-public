# Icons and visual assets

Icons support familiar actions such as reading text aloud, navigating, closing a panel, or copying writing.

## Guidelines

- Pair unfamiliar icons with text or a tooltip.
- Give icon-only buttons an accessible name.
- Keep speech controls visually consistent.
- Do not change an icon's meaning between states.
- Use borders or color changes for active state without replacing the core glyph.
- Avoid decorative imagery that competes with student writing.

Generated media and provider integrations are outside this public snapshot.
